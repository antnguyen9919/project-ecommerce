# Alexandria

E-Commerce Project: An online bookstore where users can view the book catalogues, filter and sort items per preference, add items to cart or remove them, make purchase orders, and view past orders.
Portfolio project for _Project: Getting started in Web Programming_ (IU).

## Stack

- Framework: NextJS v16, collocation of frontend(ReactJS) and backend(NodeJS).
- Runtime: Node.js 24.22.1 [CVE fixed](https://nodejs.org/en/blog/release/v24.22.1)
- Programming language: Typescript 6
- Database: SQLite via Prisma ORM
- Misc: MUI(Styling), Tanstack Query(Query management), Zod(validation), PNPM 11.28.9(Package manager), NextAuth(Auth library for nextjs, JWT strategy), Eslint v9(code linter)

Phase 1: concept. Implementation starts in Phase 2.
